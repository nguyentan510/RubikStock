# Runtime Contracts (`D2`)

Nhóm tài liệu này sẽ được kích hoạt khi application skeleton đã tồn tại.

Các artifact chuẩn dự kiến:

- OpenAPI contract do FastAPI sinh ra.
- Error catalog và định dạng problem-detail.
- Contract về idempotency và concurrency.
- Permission matrix gắn với authorization tests.
- Contract cho event/job payload khi cần.

Không duy trì thủ công thêm một API specification đầy đủ thứ hai khi OpenAPI đã được sinh ra.
